# 02. 평가 방법

전략 비교가 "운"이 아니라 "실력" 차이인지 판단하기 위한 규칙. 도구: `tools/repeat_experiments.py`, `tools/check_determinism.py`.

---

## 2-1. 같은 손님 목록 (외생 수요)

| 항목 | 내용 |
|---|---|
| 문제 | 예전에는 손님 생성이 배차 결과와 전역 난수에 따라 달라져, 전략마다 손님 목록이 달랐다 (재생 파일 지문 `7caab31d…` vs `e2b08fd0…`) |
| 결정 | 하루 호출 목록을 시뮬레이션 시작 전에 날짜·시드 전용 난수로 미리 만든다 (`demand_model.build_schedule`) |
| 검증 | 실행마다 "수요 지문"을 계산해 날짜별로 모든 전략이 같은지 확인 → 7일 × 전략 전부 동일 |

## 2-2. 결과 재현성 (해시 시드 고정)

| 항목 | 내용 |
|---|---|
| 문제 | 같은 전략·같은 손님으로 다시 돌려도 타임아웃이 298명 vs 324명처럼 달랐다. 원인은 파이썬 집합(set) 순회 순서가 실행마다 바뀌어 배차 동률 처리가 달라지는 것 |
| 결정 | 모든 실행을 `PYTHONHASHSEED=0`으로 고정 (`reproducibility.ensure_fixed_hash_seed`, 고정 안 돼 있으면 스스로 다시 실행) |
| 검증 | `tools/check_determinism.py`: 고정 시 두 번 실행 결과가 대기시간까지 동일, 고정 해제 시 다름. 재생 파일 생성 결과와 반복 실험의 같은 날짜 결과도 숫자까지 동일 |

## 2-3. 평가 날짜 7일

| 기준 | 이유 |
|---|---|
| 학습에 안 쓴 날짜 (9/7 이후) | 예측·RL 학습 기간(7/13~9/6)과 겹치면 답을 보고 푸는 셈 |
| 실측 날씨가 있는 날짜 (10/27 이전) | 날씨 파일 범위 |
| 공휴일 제외 | 추석(9/24~26), 개천절, 한글날은 수요 패턴이 특이 |
| 월~일 하루씩 | 실제 한 주의 평일:주말 = 5:2와 같게 |
| 비 온 날 3일 포함 | 날씨 반영 효과 확인 (10/13 2.6mm, 10/24 4.9mm, 10/18 27.5mm, 9~23시 기준) |
| 9/7 포함 | 기존 보고서 기준 날짜와 이어서 비교 |

→ **9/7(월), 10/13(화), 10/14(수), 9/10(목), 9/18(금), 10/24(토), 10/18(일)**

처음에는 8일(금요일 2번)이었으나, 평일:주말 비율과 설명 단순성을 위해 7일로 줄였다(이미 끝난 결과는 그대로 사용).

## 2-4. 통계 판단

| 항목 | 방법 |
|---|---|
| 짝짓기 | 같은 날짜끼리 "전략 − 순찰" 차이를 구한다 (날짜마다 수요가 달라서 짝지어야 공정) |
| 신뢰구간 | 차이의 평균과 95% 신뢰구간 (t분포) |
| 부호 검정 | 7일 중 며칠 더 나았는지, 양측 p값. 7일 모두 같은 방향이면 p = 0.016 |
| 해석 | 신뢰구간이 0을 포함하거나 p ≥ 0.05면 "확실하지 않음"으로 보고 |

## 2-5. 파라미터 조정은 검증 날짜로만

| 항목 | 내용 |
|---|---|
| 규칙 | 전략의 설정값을 고를 때 평가용 7일을 쓰지 않는다 (평가 날짜에 맞추면 결과가 부풀려짐) |
| 검증 날짜 | 9/8(화), 9/17(목) — 학습 기간 이후, 평가 7일·공휴일과 겹치지 않음 |
| 적용 사례 | 예측 재배치의 안전장치 기준(빈 택시 비율 0 / 0.2 / 0.3 / 0.4) → `04_forecast_repositioning.md` |

## 2-6. 두 수요 조건

| 조건 | 의미 | 결과 폴더 |
|---|---|---|
| 카카오 몫 (0.77, 기본) | 현실적인 카카오T 배차량 | `results/repeat/network_dispatch/`, `forecast_v2/` |
| 손님 100% | 택시가 부족한 날이 생기는 스트레스 조건 | `results/repeat/network_dispatch_full/`, `forecast_v2_full/` |

## 재현

```bash
python tools/repeat_experiments.py --jobs 2 --scenario network_dispatch --strategies patrol prepositioned rl_prepositioned forecast
python tools/repeat_experiments.py --jobs 2 --scenario network_dispatch_full --strategies patrol prepositioned rl_prepositioned forecast
python tools/check_determinism.py --hours 1 --strategy forecast
```
중간에 멈춰도 다시 실행하면 끝난 실행(`results/repeat/<이름>/runs/*.json`)은 건너뛴다.
