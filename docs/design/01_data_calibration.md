# 01. 데이터 보정 결정

시뮬레이션 손님(호출)을 실제 강남역에 맞추기 위해 바꾼 세 가지. 방법 상세는 `docs/real_data_calibration.md`, 원자료 목록은 `data/external/README.md`.

## 1-1. 시간대 비율: 2022년 1월 → 2025년

| 항목 | 내용 |
|---|---|
| 문제 | 시간대별 손님 비율을 서울시 2022년 1월 통계로 쓰고 있었다. 이 시기는 코로나 영업시간 제한이 남아 있어 밤 손님이 실제보다 적다 |
| 결정 | 서울시 「2025 서울 교통이용 통계보고서」의 시간대별 택시 이용(평일/주말)과 강남구 월별 승차(평일/주말)로 교체 |
| 근거 | 9~23시 비중이 평일 72.9%(2022.1) → 66.7%(2025)로 6%p 차이. 강남구 월별 평일/주말 배율 0.93~1.06 / 0.82~0.90 |
| 대안 | 2024년 12월 보도자료(자정~1시 7.0% 등) — 일부 시간대만 있어 기각 |
| 검증 | 생성된 8주 호출의 시간대 분포가 2025 통계와 일치 (`notebooks/01_EDA_and_Spatial.ipynb`) |
| 한계 | 서울 전체 비율이라 강남역 특유의 심야 집중은 덜 반영. 요일 안 배율은 2025 보고서에 없어 2022년 1월 값을 평일 안·주말 안 상대값으로만 사용 |
| 파일 | `data/external/seoul_taxi_hourly_2025.csv`, `data/external/gangnam_taxi_pickups_2025.csv`, `module1_simulation/demand_model.py` |

## 1-2. 손님 규모: 전체 승차량 → 카카오T 몫 (0.77)

| 항목 | 내용 |
|---|---|
| 문제 | TIMS 승차량은 길에서 손 들어 잡은 손님, 다른 앱 손님까지 모두 포함한다. 이 손님들은 카카오 배차 시스템을 거치지 않는다 |
| 결정 | `real_demand_scale` = 0.77 (앱 호출 비중 × 카카오 점유율) |
| 근거 | 서울시 택시 시민만족도 조사: 앱 호출 약 80% / 공정거래위원회 카카오모빌리티 제재 발표: 앱 일반 호출 중 카카오 약 96% (2022년 기준) → 0.80 × 0.96 ≈ 0.77 |
| 대안 | 1.0(전체) — 과제 대상(카카오T 배차)보다 수요를 부풀려 기각. 단, **민감도 시나리오로 함께 실험** (`--scenario network_dispatch_full`) |
| 검증 | 두 조건 모두에서 전략 순위 결론이 같음 (순찰이 미리 옮기는 규칙·RL보다 나음) |
| 한계 | 서로 다른 해의 조사 두 개를 곱한 근사값 |
| 파일 | `config.json` → `real_demand_scale` |

## 1-3. 날씨: 실행 순간의 실시간 날씨 → 그 날짜의 실측 날씨

| 항목 | 내용 |
|---|---|
| 문제 | 과거 날짜를 시뮬레이션해도 "실행하는 순간"의 실시간 날씨가 들어갔다. 예측 모델 학습에도 합성 날씨 8일치(8/30~9/6)만 있어 나머지 기간은 날씨 없이 학습됐다 |
| 결정 | Open-Meteo 과거 날씨(강남역 좌표, 1시간)를 받아 그 날짜·시간의 강수로 호출량을 조정: `1 + 0.0199 × 강수mm` (최대 30mm) |
| 근거 | 강수 계수 1mm당 +1.99%(95% CI +0.23~+3.79%, p=0.027): 서울 열린데이터광장 「수도권 생활이동」 강남구 출발 × 기상청 ASOS 서울(108), 2026-08-10~31 시간 단위 회귀 (`docs/weather_coefficient.md`) |
| 대안 | 기온 계수(+2.73%/°C, p<0.001) — 8월(21.5~34.3°C)로만 추정돼 9~10월에 외삽할 수 없어 미적용 |
| 검증 | 56일 학습 로그 전부 실측 날씨 연결(결측 0%). 일별 (생성 − 기대)/√기대 평균 0.17, 표준편차 1.04 → 포아송과 일치 |
| 한계 | 계수는 택시만이 아닌 전체 이동으로 추정한 근사값. Open-Meteo는 재분석 격자값(약 9~11km)이라 국지성 소나기는 약하게 나옴 |
| 파일 | `data/external/weather_강남역_2026-07-01_2026-10-27.csv`, `module1_simulation/weather_history.py`, `data/loaders/fetch_weather_history.py` |
