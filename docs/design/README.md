07·08의 도로·수요 설정은 팀 기본값을 바꾸지 않고 프리셋 **「근거기반_현실화」**(`presets/default/근거기반_현실화.json`)로 둔다.

프리셋은 설정 GUI 기본 탭의 프리셋 버튼이나 `python main.py play --config presets/default/근거기반_현실화.json`으로 쓴다.

- 모든 설정값의 근거는 [08 근거 대장](08_evidence_register.md). 구역 안 하차 비율은 택시 기종점 실측(5.4%).
- 수요 쪽 가정은 결론을 ±2.3%p 안에서만 움직이고, 택시 대수·복귀 속도가 ±20%p, 강남역 평일 시간대(밤 집중)를 쓰면 −8.5%p.
- 원자료: `results/repeat/twin_v3/summary.md`, `results/repeat/sens_*/`, `results/repeat/sens3_*/`
- RL·예측 재배치는 ldk의 예전 모델 결과다. jwy 브랜치는 2026-11-06에 수요 예측을 다시 학습했고 RL도 다시 학습할 예정 → 프리셋 조건으로 다시 돌려 갱신한다.
