## 3. 왜 날씨·휴일 피처가 효과가 없나 — 데이터 쪽 원인 (팀 결정 필요)

합성 생성기(`data/generate.py`)의 특성 때문이지 피처 설계 문제가 아니다.

1. **강수가 5분마다 독립 난수**다. 실제로는 비가 몇 시간 지속되지만(강남역 실측 1시간 자기상관 0.77), 합성 강수의 5분 자기상관은 0.001이다. 시각 t의 강수는 t+5분의 강수와 무관하므로, 누수 없이 과거만 쓰는 모델은 미래 강수 효과를 배울 수 없다. 강수가 수요를 올리기는 한다(시간대·셀 통제 후 5.5mm일 때 +27%) — 다만 예측 불가능한 형태로.
2. **공휴일이 8/15 하나**이고 2026-08-15는 토요일이라 주말과 구분되지 않는다. 배수도 주말과 같은 0.8이라 공휴일만의 효과가 데이터에 없다.
3. 기온은 매일 같은 사인 곡선 + 작은 잡음이라 시간대 피처와 완전히 겹친다.

제안 (생성기 담당 2번·외부데이터 1번): 강수를 시간 단위 에피소드로 만들거나(예: 시작 확률 낮게, 시작하면 2~6시간 지속) 실측 시간별 날씨(Open-Meteo, 8주)를 그대로 넣어 호출을 생성하고, 계수는 이동규 님 실측 추정치(강수 1mm당 +1.99%, 기온 1℃당 +2.73%)를 쓰면 순환논리 없이 날씨 신호가 생긴다. 공휴일은 `holidays` 달력(대체공휴일 8/17 포함)으로 넣고 배수를 주말과 다르게 둔다. 그렇게 바꾼 뒤 같은 ablation을 다시 돌리면 3~4행이 움직여야 정상이다.
